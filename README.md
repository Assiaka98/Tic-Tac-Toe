# Morpion / Tic-Tac-Toe Pro

Jeu de Morpion en JS vanilla, réalisé dans le cadre de ma montée en compétence front.

**Live Demo:** https://assiaka98.github.io/Tic-Tac-Toe/

**Stack:** HTML5, CSS3, JavaScript (logique de jeu, gestion des tours, détection victoire)
**Fonctionnalités:**
- 2 joueurs
- Détection automatique du gagnant / match nul
- Reset partie
- Responsive

**Ce que j'ai appris:** manipulation du DOM, state simple sans framework.
